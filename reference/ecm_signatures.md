# ECM Niche Signatures

Gene signatures for three ECM niche types used for UCell scoring.

## Usage

``` r
ecm_signatures
```

## Format

A named list with three elements:

- Vascular:

  Genes associated with vascular ECM

- Basement:

  Genes associated with basement membrane

- Interstitial:

  Genes associated with interstitial matrix

## Examples

``` r
data(ecm_signatures)
names(ecm_signatures)
#> [1] "Interstitial" "Basement"     "Vascular"    
```
