# Annotate ECM domains (deprecated)

Deprecated alias for
[`annotate_ecm_niches()`](https://Theayomideo.github.io/matrispace/reference/annotate_ecm_niches.md).
Use the new name in new code.

## Usage

``` r
annotate_ecm_domains(seurat_obj, markers_path = NULL)
```

## Arguments

- seurat_obj:

  A Seurat object with SCT assay

- markers_path:

  Path to Excel file with ECM niche markers. If NULL, uses built-in
  markers from inst/extdata.

## Value

Same as
[`annotate_ecm_niches()`](https://Theayomideo.github.io/matrispace/reference/annotate_ecm_niches.md).
